# Coaching

Public routes: `/coaching`, `/coaching/new`, `/coaching/:id`, `/coaching/:id/edit`.
The initial launch contains **no guides or sample posts**. Any active signed-in Discord member can publish a guide with a title, hook, cover and plain-text body. Only its author can edit the text/image. Hearts are one per member per guide, set idempotently; editing retains hearts. Public cards are three across on desktop, two on tablet, one on mobile.

Owner/admin can hide or restore guides. Authors can remove their own posts; staff can remove posts through the API. Removal is a soft delete, and hidden/deleted covers cannot be fetched anonymously. The private moderation log records these actions. Posts and member-linked heart data live in D1. JPEG/PNG/WebP covers up to 5 MB use the existing `PLAYER_PHOTOS` R2 binding under the isolated `coaching/` prefix. Old covers are removed only after successful replacement. Removed guides and covers are retained for recovery; no automatic deletion of existing media is performed.

Run `migrations/20261011_coaching.sql` on the production DB before publishing source. This creates new tables/indexes only and inserts no content. Production's authentication, Turnstile and R2 bindings stay unchanged. Never seed production with QA users or posts. Test using `node --test scripts/coaching.test.mjs` and the standard site suite. The API uses server-side ownership, active session checks, same-origin writes, bounded upload streams, per-member rate limits, and revision conflicts to prevent stale updates. Guide content renders only as escaped plain text, never user-supplied HTML or scripts.

For browser QA, `node scripts/coaching-preview.mjs --member --fixtures` runs a **loopback-only, in-memory** environment. Its synthetic records, fake QA session and image map disappear on process exit and never touch Cloudflare. Omit flags to test the signed-out empty state. The publisher excludes this script. Browser QA covered the three-column desktop layout, one-column 390px mobile layout with no horizontal overflow, hearts, author editing, retained hearts after edits, cover selection and complete local submission. Full site suite: 178 passed, with two known baseline roster-count failures (expected 9 vs current 10 teams), unrelated to Coaching.
